# AGENTS.md — памятка проекта

## Игра
«Выживи на совещании» — браузерная мини-игра: Вова на совещании листает мемы на телефоне, пока босс не смотрит. Продержаться 60 секунд, не получить 2 замечания.

## Технологии
- Vanilla HTML/CSS/JavaScript (ES2020+), **без сборки и фреймворков** (решение из design/decisions.md)
- Сцена: Canvas 2D, UI: DOM поверх canvas
- Весь баланс и тексты — в `js/config.js`, не в коде

## Как запустить локально
Открыть `index.html` в браузере (двойной клик) — проект статический, сервер не нужен.
Если что-то не работает без сервера — `python -m http.server 8000` в папке проекта, открыть http://localhost:8000

## Как проверить код
- Ошибки смотреть в консоли браузера: F12 → Console (десктоп)
- На телефоне: подключить кабель, Chrome → chrome://inspect (Android) или Safari → Develop (iOS)
- Синтаксис JS: `node --check js/<файл>.js` (Node.js установлен через winget)

## Обязательный цикл работы ИИ (для каждого шага)
1. **Сделать задачу** (код/ассеты/конфиг).
2. **Самостоятельно проверить результат** — открыть `debug.html` (или запустить игру) и убедиться, что всё работает: спрайты на месте, позиции верные, ошибок в консоли нет. Не просить пользователя проверять непроверенное.
3. **Подготовить локальный `index.html` к проверке** — убедиться, что он подключает все актуальные файлы игры, и сообщить пользователю: «открой `index.html` в браузере (двойной клик)». Пользователь проверяет изменения локально, без сервера.
4. **Подготовить изменения к пушу** — сделать коммит с понятным сообщением на русском и убедиться, что ветка синхронна с `origin/main` (перед коммитом: `git fetch` + `git status`; никогда не переписывать уже запушенные коммиты через `--amend`/rebase). Пользователь пушит сам.
5. **Только после этого** сообщать пользователю: что изменилось, как проверить локально, что проверить на телефоне после пуша.
- Инструменты самопроверки: `tools/diag*.ps1` (анализ картинок), `tools/analyze_sheet.ps1` (bbox кадров), `tools/preview_flip.ps1` (превью сцены на разных экранах), `tools/selfcheck.js` (спрайты и конфиг), `node --check` (синтаксис).

## Договорённости

- Числа баланса — только в `js/config.js`
- Комментарии в коде — короткие, на русском
- Дизайн меняет только пользователь / режим «Геймдизайнер»; ИИ сообщает о проблемах, а не меняет молча
