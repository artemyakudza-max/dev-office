# «Выживи на совещании» — дизайн-документы

## Статус проекта
- Мини-игра №1 (Вова): **реализована и задокументирована (as-built)** — код v0.9.35, деплой на GitHub Pages
- Мини-игра №2 (Чекеридис): **утверждены название «Цицеридис» и UI-оболочка как у Вовы; механика геймплея в обсуждении**
- Цель: веб-игра по ссылке, чтобы удивить коллег. Смешно, быстро, без установки.

## Ключевые факты
- Жанр: набор мини-игр по персонажам (оболочка «выбор персонажа» общая)
- Мини-игра Вовы: «Успеть за 60 секунд» — босс у флипчарта, Вова с телефоном под столом
- Мини-игра Чекеридиса: «Цицеридис» — тема: пьяная философия на корпоративе; механика обсуждается
- UI-оболочка мини-игр едина: пауза, «ПРАВИЛА», обучение, автопауза, финалы (требование автора)
- Платформа: браузер (ссылка), мобайл-first (тач), десктоп — зажатая мышь
- Сессия: ~1 минута (раунд 60 с, потолок 70 с)
- Аудитория: офисные коллеги автора
- ТЗ для ИИ-разработчика: [tz-vova-minigame.md](tz-vova-minigame.md)

## Открытые вопросы
- [ПРОВЕРИТЬ В ПЛЕЙТЕСТЕ] Окно гнева 2,5 с не бесит; телеграф и фальстарт читаются без звука на телефоне
- [ДОПУЩЕНИЕ] Код-арт фолбэк босса (лысый мужчина) не совпадает с Леной из спрайта — страховка, на проде не виден
- [ОТКРЫТО] «Цицеридис»: механика геймплея не утверждена; реальные фразы Чекеридиса с корпоратива соберёт автор
