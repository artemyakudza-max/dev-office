# «Выживи на совещании» — дизайн-документы

## Статус проекта
- Этап: **концепт утверждён** → следующий шаг: циклы и системы
- Цель: веб-игра по ссылке, чтобы удивить коллег. Смешно, быстро, без установки.

## Оглавление
- [concept.md](concept.md) — концепт (one-pager). Статус: утверждено
- [ideas.md](ideas.md) — банк идей (4 альтернативы). Статус: архив
- [decisions.md](decisions.md) — журнал решений. Статус: ведётся
- [assets/README.md](assets/README.md) — арт-ассеты. Статус: vova.png на месте
- [features/vova-minigame.md](features/vova-minigame.md) — спецификация мини-игры Вовы. Статус: черновик v3
- [tz-vova-minigame.md](tz-vova-minigame.md) — техническое задание для ИИ-разработчика. Статус: черновик v1, на утверждение

## Ключевые факты
- Жанр: мини-игра «сценка + реакция» (босс у флипчарта, Вова с телефоном под столом)
- Платформа: браузер (ссылка), мобайл-first (тач), десктоп — зажатая мышь
- Сессия: ~1 минута (раунд 60 с, потолок 70 с)
- Аудитория: офисные коллеги автора
- ТЗ для ИИ-разработчика: [tz-vova-minigame.md](tz-vova-minigame.md)
