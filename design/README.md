# «Выживи на совещании» — дизайн-документы

## Статус проекта
- Этап: **мини-игра Вовы реализована и задокументирована (as-built)** — код v0.9.35, деплой на GitHub Pages
- Цель: веб-игра по ссылке, чтобы удивить коллег. Смешно, быстро, без установки.

## Оглавление
- [concept.md](concept.md) — концепт (one-pager). Статус: утверждено
- [ideas.md](ideas.md) — банк идей (4 альтернативы). Статус: архив
- [decisions.md](decisions.md) — журнал решений. Статус: ведётся
- [assets/README.md](assets/README.md) — арт-ассеты. Статус: vova.png на месте
- [features/vova-minigame.md](features/vova-minigame.md) — спецификация мини-игры Вовы. Статус: черновик v3 (частично устарела — актуальная версия в ТЗ)
- [tz-vova-minigame.md](tz-vova-minigame.md) — ТЗ мини-игры Вовы. Статус: **as-built v2** — отражает фактический код v0.9.35, включая карту расхождений с v1

## Ключевые факты
- Жанр: мини-игра «сценка + реакция» (босс у флипчарта, Вова с телефоном под столом)
- Платформа: браузер (ссылка), мобайл-first (тач), десктоп — зажатая мышь
- Сессия: ~1 минута (раунд 60 с, потолок 70 с)
- Аудитория: офисные коллеги автора
- ТЗ для ИИ-разработчика: [tz-vova-minigame.md](tz-vova-minigame.md)

## Открытые вопросы
- [ПРОВЕРИТЬ В ПЛЕЙТЕСТЕ] Окно гнева 2,5 с не бесит; телеграф и фальстарт читаются без звука на телефоне
- [ДОПУЩЕНИЕ] Код-арт фолбэк босса (лысый мужчина) не совпадает с Леной из спрайта — страховка, на проде не виден
