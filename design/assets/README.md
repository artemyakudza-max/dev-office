## Исходники по мини-играм
- **Вова**: `design/assets/Vovan/` — карточка, спрайт-листы, фон, финалы.
- **Чекеридис**: `design/assets/Chekeridis/` — спрайт-лист, финальные портреты, фон.

## Соглашение об именах
- Исходники: `design/assets/<Персонаж>/<имя>.png` (латиница, нижний регистр)
- Сжатые копии для игры: `assets/characters/` и `assets/sprites/` (создаёт ИИ через `tools/`)
